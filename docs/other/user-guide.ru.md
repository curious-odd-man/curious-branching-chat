# BranchChat — руководство пользователя

BranchChat — это программа для Windows, похожая на обычный чат, но с важным отличием: любой фрагмент сообщения можно
выделить и ответить именно на него. Ответ создаёт **ветку** — отдельное маленькое обсуждение, привязанное к этому
фрагменту. Всё обсуждение хранится в **одном файле** `.branchchat`, который удобно отправлять через WhatsApp.

Программа работает без интернета. Интернет нужен только для проверки обновлений.

## 1. Установка

1. Скачайте `BranchChat-Setup.exe` со страницы релизов проекта на GitHub.
2. Запустите файл. Права администратора не нужны: программа устанавливается только для вашей учётной записи.
3. На странице «Файлы обсуждений» можно разрешить открывать файлы `.branchchat` двойным щелчком. Это можно
   включить или выключить позже: **Файл > Настройки…**

### Предупреждение Windows (SmartScreen)

Программа пока **не имеет цифровой подписи** (подпись платная). Поэтому при первом запуске установщика Windows может
показать синее окно «Windows защитила ваш компьютер». Это не означает, что файл опасен: Windows просто не знает
издателя. Чтобы продолжить:

1. В окне нажмите **Подробнее**.
2. Нажмите **Выполнить в любом случае**.

Если браузер пишет, что файл «редко скачивают», выберите **Сохранить** или **Оставить**.

### Как убедиться, что файл не подменён

На странице каждого релиза указана контрольная сумма SHA-256. Проверка:

1. Откройте PowerShell в папке, куда скачан файл.
2. Выполните: `Get-FileHash .\BranchChat-Setup.exe -Algorithm SHA256`
3. Значение должно совпасть со значением на странице релиза. Если не совпало — не запускайте файл.

Скачивайте программу только со страницы релизов проекта.

## 2. Первые шаги

- **Новое обсуждение:** меню **Файл > Новое обсуждение**, затем выберите, где сохранить файл. Дальше сохранение идёт
  само: кнопки «Сохранить» нет, рядом с названием показывается «Сохранено».
- **Открыть обсуждение:** двойной щелчок по файлу `.branchchat`, перетаскивание на окно или **Файл > Открыть…**
- **Имя:** при первой отправке программа спросит ваше имя. Изменить его можно в **Настройки…**; старые сообщения
  сохранят прежнее имя.
- **Отправка:** кнопка «Отправить» или **Ctrl+Enter**.

### Недавние обсуждения

На начальном экране (когда ни одно обсуждение не открыто) показан список недавних обсуждений: щёлкните по названию,
чтобы открыть. Кнопка ✕ убирает запись из списка (сам файл не удаляется), «Очистить список» убирает все записи.
Если файл перемещён или удалён, запись выглядит серой с пометкой «файл не найден».

Тот же список есть в меню **Файл > Открыть недавние** и в списке переходов на значке BranchChat в панели задач
(правый щелчок).

По умолчанию при запуске BranchChat сам открывает последнее обсуждение. Если запустить программу двойным щелчком по
файлу, откроется только этот файл. В **Файл > Настройки…** можно выключить автоматическое открытие и изменить, сколько
недавних обсуждений помнить (по умолчанию 10; 0 — не хранить список).

## 3. Оформление и картинки

Над полем ввода — панель: заголовки, **жирный**, курсив, подчёркивание, списки, цвет текста и выделение, ссылки.
Картинки можно вставить из буфера обмена (Ctrl+V), перетащить в поле или добавить кнопкой. Щелчок по картинке
открывает её крупно. Ссылка открывается в браузере только по вашему щелчку.

Правописание проверяется средствами Windows: слова с ошибками подчёркиваются, правый щелчок показывает варианты.
Если русской проверки нет, добавьте русский язык в параметрах Windows («Время и язык»).

## 4. Ветки

1. Выделите текст в сообщении, нажмите **Ответить на это** и напишите ответ.
2. Слева, в панели **Ветки**, видны все ветки: **Активные** и **Закрытые**. Вложенные ветки (ветка от ветки) показаны
   вложенно.
3. В ветке сверху показана цитата и путь; кнопка **К исходному сообщению** возвращает к тому месту, откуда ветка
   началась. Над вашими ответами — предыдущие сообщения для контекста (только чтение).
4. Ветку можно назвать, **закрыть** и позже **открыть снова**.

## 5. Непрочитанное

Новые сообщения других людей выделены. Их можно отметить прочитанными по одному, по всей ветке или все сразу;
ответ в ветке тоже отмечает её сообщения прочитанными. В панели веток у каждой ветки есть счётчик непрочитанных.
У каждого сообщения видно, кто его прочитал: зелёная ✓ — прочитал хотя бы один участник, две зелёные ✓✓ —
прочитали все. Пока никто не прочитал, отметки нет. Автор сообщения не считается. Нажмите на отметку, чтобы увидеть
имена.

**Важно:** отметки о прочтении хранятся в файле. Все, у кого есть файл, увидят ваши отметки. Программа предупреждает
об этом один раз.

## 6. Как поделиться обсуждением

1. Отправьте файл `.branchchat` через WhatsApp (как документ) или любым другим способом.
2. Получатель сохраняет файл и открывает его в BranchChat, читает, отвечает.
3. Он отправляет файл обратно. Ваши сообщения и его сообщения окажутся в одном файле.

Картинки лежат внутри файла и видны на любом компьютере. Не открывайте один и тот же файл на двух компьютерах
одновременно и не рассылайте разные копии параллельно: копии не объединяются автоматически.

Если файл повреждён, программа покажет сообщение и продолжит работать; другие обсуждения не пострадают.

### Ключ шифрования

В **Файл > Настройки…** есть раздел «Ключ шифрования». Ключ создаётся сам, когда вы впервые открываете этот раздел.
Он понадобится для общих обсуждений в следующих версиях программы.

- Закрытая часть ключа хранится только на этом компьютере и защищена вашей учётной записью Windows. Никто её не
  получает.
- **Отпечаток** — 8 групп по 4 знака. Сверяйте отпечаток с другим человеком по телефону или при встрече.
- **Скопировать мой ключ** и **Сохранить мой ключ…** передают только открытую часть ключа. Её можно отправить через
  WhatsApp. Для этого сначала укажите своё имя.
- Если вы переустановите Windows или войдёте под другой учётной записью, программа создаст новый ключ с новым
  отпечатком и сообщит об этом.

## 6а. Общие обсуждения (синхронизация через общую папку)

Общее обсуждение не нужно пересылать файлом: изменения сами приходят к участникам через общую папку, например папку
Google Диска на компьютере. Сообщения шифруются, поэтому служба хранения не может их прочитать.

**Что видит служба хранения (например, Google).** Кто имеет доступ к папке, сколько в ней файлов, их размеры и время.
Текст сообщений и картинки она не видит.

### Подготовка

1. Создайте папку в программе синхронизации (например, в Google Диске) и откройте доступ участникам с правом
   редактирования.
2. В Google Диске в режиме потоковой передачи нажмите на папку правой кнопкой и выберите «Доступно офлайн».
3. Проверьте, что папка видна в проводнике как обычная папка (например, `G:\Мой диск\Общая`).

### Создать общее обсуждение

1. **Файл > Новое общее обсуждение…** (или для открытого обсуждения: **Файл > Сделать обсуждение общим…**).
2. Нажмите **Выбрать папку…** и выберите общую папку. Программа проверит, что в неё можно писать.
3. Участники открывают **Файл > Присоединиться к обсуждению…** и выбирают ту же папку — их ключи появляются в
   списке. Ключ можно также получить файлом `.bckey` или текстом (через WhatsApp).
4. **Сверьте отпечаток каждого участника** по телефону или при встрече. Отметьте «Пригласить» только для тех, чей
   отпечаток совпал.
5. Нажмите **Создать и пригласить** и выберите, где сохранить файл обсуждения. Файл должен быть **вне** общей папки.

### Присоединиться

1. **Файл > Присоединиться к обсуждению…**, выберите общую папку.
2. Дождитесь приглашения. **Сверьте отпечаток пригласившего** с тем, что он вам скажет. Если отпечаток другой, не
   принимайте приглашение.
3. Нажмите **Отпечаток совпадает — сохранить обсуждение…** и выберите место для файла (вне общей папки).

### Как это работает

- Сообщения, ветки, закрытие веток, названия веток, отметки о прочтении и смена имени приходят к другим участникам
  сами. Сообщения упорядочены одинаково у всех. Сообщение, написанное кем-то без интернета, может появиться выше уже
  прочитанных — оно будет отмечено как непрочитанное.
- Большие картинки приходят частями по 4 МБ. Пока части в пути, сообщение показано с полосой загрузки. Отметить его
  прочитанным или ответить на него можно, когда оно загрузится полностью.
- В этой версии синхронизация работает, пока программа открыта.
- Кнопка 👥 в заголовке показывает участников.

### Копии

- **Файл > Отправить копию…** сохраняет копию без списка участников, её можно отправить через WhatsApp как обычное
  обсуждение. Копия не синхронизируется.
- Копия, сделанная в проводнике, тоже открывается как отдельное обсуждение: изменения в ней никуда не отправляются.
- Если вы переместили или переименовали файл общего обсуждения, программа спросит, тот ли это файл.

### Доставка и проверка папки

- У каждого сообщения в общем обсуждении (и у ваших, и у сообщений других участников) одна отметка. Автор сообщения
  не считается:
    - 🕓 — сообщение ещё записывается в общую папку;
    - серая ✓ — сообщение есть в общей папке, но ещё не все участники его получили (для вашего сообщения: записано в
      общую папку на этом компьютере, это ещё не значит, что ушло в облако);
    - две серые ✓✓ — получили все участники;
    - зелёная ✓ — прочитал хотя бы один участник;
    - две зелёные ✓✓ — прочитали все.

  Нажмите на отметку, чтобы увидеть каждого участника.
- Если сообщение кому-то не дошло, программа запишет его снова, когда этот участник появится в сети.
- Если общая папка недоступна или нет прав на запись, под заголовком появляется жёлтая строка с объяснением.
- Кнопка **⟳ Проверить папки** проверяет общую папку сразу.

### Ограничения этой версии

- Пока нельзя пригласить нового участника после создания и нельзя вернуться после потери ключа.
- Нельзя выйти из обсуждения или удалить участника.

## 7. Обновления

Через некоторое время после запуска программа проверяет, есть ли новая версия на GitHub. Если есть, вверху появляется
сообщение. Нажмите **Подробнее**, затем **Скачать**; обновление установится при следующем закрытии программы
или по кнопке **Перезапустить и установить**. Ваши обсуждения обновление не меняет.
Автоматическую проверку можно выключить: **Настройки…** > «Проверять обновления автоматически». Проверить вручную:
**Справка > Проверить обновления…**

## 8. Клавиатура и экран

- Все действия доступны с клавиатуры: **Tab** / **Shift+Tab** — переход, **Esc** — закрыть окно.
- Программа учитывает масштаб экрана Windows (100–200 %) и режим высокой контрастности.

## 9. Удаление

**Параметры Windows > Приложения > BranchChat > Удалить.** Ваши файлы `.branchchat` не удаляются.

## 10. Если что-то не так

- Файл не открывается — проверьте, что он не пустой и скачан полностью (попросите отправить его ещё раз).
- Двойной щелчок не открывает BranchChat — включите связь в **Настройки…** (если файлы связаны с другой программой,
  измените это в параметрах Windows: «Приложения по умолчанию»).
