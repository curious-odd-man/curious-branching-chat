## Установка

Скачайте `BranchChat-Setup.exe` и запустите. Права администратора не нужны.

Приложение пока не имеет цифровой подписи, поэтому при первом запуске Windows может показать синее окно
«Windows защитила ваш компьютер» (SmartScreen). Нажмите **Подробнее**, затем **Выполнить в любом случае**.
Перед запуском можно сверить контрольную сумму (см. ниже).

## Проверка файла

SHA-256 файла `BranchChat-Setup.exe`:

`<вставляется автоматически>`

Проверка в PowerShell:

    Get-FileHash .\BranchChat-Setup.exe -Algorithm SHA256

Значение должно совпасть с указанным выше.

## Обновление

Установленные копии находят новую версию сами и предлагают её скачать. Файлы обсуждений обновление не меняет.
